# Wingman

*Values first. Then you meet.*

Wingman finds the person in the room who shares your values — and walks you all the way to the first hello. No swiping, no photos.

Built at **VexoHacks @ Y Combinator — November 14, 2026** by Xiya (Holly) Tang and Will Li.

**Stack:** Vexo Open band · Gemini 4 · ElevenLabs · Deepgram · Mastra
